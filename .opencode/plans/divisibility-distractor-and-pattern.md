# Remove "divisible by x and y" distractor from divisibility rules

## Description

In `numbersTrivia.ts`, the `divisibilityRules` sub-type generates a distractor using the template:

```
The number is divisible by {n} and {n % 2 === 0 ? n / 2 : 2}.
Die Zahl ist durch {n} und {n % 2 === 0 ? n / 2 : 2} teilbar.
```

This produces answers like "Die Zahl ist durch 3 und 2 teilbar", "Die Zahl ist durch 4 und 2 teilbar", etc. The template is problematic because:

- The correct answer for `k=6` is "Die Zahl ist durch 2 und 3 teilbar." (`CORRECT_DIV_RULES`, line 142) — it shares the same **"divisible by x and y"** structural pattern. A distractor with identical grammar (only different numbers) undermines the discrimination the exercise is testing.
- For every other `k`, the generated rule is simply wrong (e.g. "durch 3 und 2 teilbar" is not a valid divisibility rule for 3), but the **form** of the answer mimics the correct answer for 6, causing confusion across the whole exercise pool.
- Currently only `k=6` is filtered (line 296: `if (k === 6 && r.en.startsWith('The number is divisible by 6 and')) return false;`), but the template still fires for all other `k` values.

## Acceptance Criteria

1. Remove the "divisible by n and y" entry (the third template, currently on lines 278–281) from `wrongTemplates` in the `divisibilityRules` case of `generateNumbersTrivia`.

2. Remove the now-unnecessary `k=6` filter at line 296

   ```ts
   if (k === 6 && r.en.startsWith('The number is divisible by 6 and')) return false;
   ```

3. Verify that no generated divisibility-rules exercise ever contains a distractor matching the pattern `/Die Zahl ist durch \d+ und \d+ teilbar/`.

## Acceptance verification (tests)

In `src/lib/exercises/numbersTrivia.test.ts`, add a test that:

- Generates divisibility-rules exercises for many seeds across all complexities
- Inspects `exercise.data.ruleTexts` (the `{ en, de }[]` array)
- Asserts that no rule's `de` field matches the pattern `/^Die Zahl ist durch \d+ und \d+ teilbar\.$/`
- After the fix, the only `de` string matching that pattern should be the `k=6` correct answer (`'Die Zahl ist durch 2 und 3 teilbar.'`), which is tagged `correct: true` and lives in the correct slot — not among the distractors
