# Exercises
## Multiplication tables
### Compute squares of numbers
First level is $2^2$-$10^2$, highest level is $10^2$-$50^2$.
Prompt: x^2 = ?

### Is this number square?
Roll a two-sided die. If it is yes, show a random square number of appropriate complexity. If it is no, show a random (non-square) number of appropriate complexity. Ask the user whether the number is square, and if it is, what its root is. Prompt: Is x a square? Answer: No (button), Yes (text).
